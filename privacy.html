Privacy Policy – Thai Shorts Uploader

Effective date: 29 October 2026

Thai Shorts Uploader is a private tool used only by the owner of the YouTube channel PsychologyLabTH to upload videos that the owner created to the owner's own YouTube channel.

Google user data we access

The app requests only the YouTube Data API scope youtube.upload, which lets it upload videos to the authorized channel. It does not read, collect, or store any other Google account data such as email, contacts, viewing history, or channel analytics.

How data is used and stored

The OAuth access token is stored only on the owner's personal computer and is used solely to upload videos. No data is sent to any server other than Google's YouTube API. No data is sold, shared, or transferred to third parties, and none is used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The token stays on the owner's computer until it is deleted or access is revoked. Access can be revoked at any time at myaccount.google.com/permissions.
